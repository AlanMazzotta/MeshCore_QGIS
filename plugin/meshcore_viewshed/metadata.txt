about=Pulls repeater positions from the public MeshCore map API, downloads a Copernicus 30m DEM via OpenTopography, runs GDAL viewshed analysis for every node, stacks them into a cumulative coverage raster, generates a directional coverage raster (8 compass sectors), and enriches the node layer with coverage area, peer connectivity, and dominant direction attributes.

    External dependencies (install once via OSGeo4W Shell on Windows, or a terminal on Linux/macOS):
    pip install msgpack geojson requests

    An OpenTopography API key is required for DEM download (free account at https://opentopography.org).
    The Signal Quality heatmap feature additionally requires a MeshCore Observer node logging packets to disk.
